# FinOS eKYC SDK — public distribution

This repository ships **prebuilt binaries only** (iOS XCFrameworks, Android AARs).
Source code lives in a separate private repository.

- `ios/` — XCFrameworks (device slices) consumed via CocoaPods / Swift Package Manager.
- `android/` — AARs (`asia.finos:*`) consumed via Maven / GitHub Packages.

Version: 2.0.3
